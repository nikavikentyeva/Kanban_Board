# Kanban Board

Интерактивная доска задач в стиле Trello для управления проектами и рабочими процессами. Пользователь может создавать доски, добавлять колонки (например, «В работе», «На проверке», «Готово») и перемещать задачи между ними с помощью drag-and-drop.


## Стек

- **Vue 3** (Composition API, `<script setup>`)
- **TypeScript** (strict mode)
- **Vite** (сборка)
- **Pinia** (state management)
- **Vue Router**
- **Vitest** (unit-тесты)

## Скрипты

| Команда | Описание |
|---------|----------|
| `npm install` | Установка зависимостей |
| `npm run dev` | Запуск dev-сервера |
| `npm run build` | Сборка для production |
| `npm run test` | Запуск unit-тестов |
